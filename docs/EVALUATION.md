Trigger: the development error analysis, where 11 of 16 misses were table rows whose size was written this way. (3) A hybrid arm B4 (slide 11, arm C) is added: B1's category, replaced by the rule category from B1's own features when they disagree; it is derived from the B1 run without new model calls. **Review of Europe PMC candidates.** Europe PMC candidate rows were pre-screened with AI assistance against a fixed checklist (CT/MRI LI-RADS v2018; imaging findings present in the findings text; reference category stated separately; at-risk liver; untreated observation; open licence), and every decision was confirmed by a team member.
**Rules.** Held-out cases are scored only with `RADS_RUN_TEST=1`; every test run is logged with its git commit and prompt hash (`data/real/test_runs.log`). A prompt change must come from a development error and cite the LI-RADS v2018 definition it implements; every results file stores the prompt hash.

## 10. Limitations

- Small real-case sample: confidence intervals are wide; the test set is used once.
- Selection bias: published and teaching cases over-represent clear-cut LR-5 and LR-M; they are not a consecutive clinical series.
- Category imbalance: published case reports over-represent definite HCC (LR-5), so the real-case set is category-imbalanced; results are reported per category, and LR-3 / LR-4 numbers rest on very few cases and must not be over-interpreted.
- No radiologist validation and no second annotator yet: no radiologist has confirmed the references, the error attribution or the reviewed Europe PMC cases, and inter-annotator agreement is not yet collected (single reviewer).
- LI-RADS only: Lung-RADS, BI-RADS and an external RXL-RADSet evaluation were planned and are not done.
- The open CT datasets have no LI-RADS feature labels (APHE, washout, capsule); those exist only in AMPLIFAI (access pending).
- WAW-TACE phase codes are unverified against the dataset paper.
- Determinism: before a fixed seed and context size were set, LLM output at temperature 0 depended on the order of calls on Ollama (PMC001 changed category); with seed 42 and a 4096-token context the development set was identical across six runs. Determinism is measured, not guaranteed.
- The robustness test uses rule-generated gold and is reported as robustness, never as accuracy. It is not held out: its error list informed the APHE definition, which quotes one of the generator's phrasings, so part of its last gain reflects the generator's vocabulary.
- Clustered cases: one article (PMC8122342) contributes 11 of the 27 real cases (rows of one per-lesion table), all in dev; the 27 cases come from 16 independent sources.
- Small test set: forcing every inspected case into dev leaves 8 test cases (dev 19 / test 8), so test intervals are wide.
