Free text can contradict itself

A report can describe the findings of one category and state another. Nothing checks it.

Language model alone – of generated reports contradicted the model's own findings
RADS-Envelope – contradictions By construction: the rule table computes the category.

How it works

  1. 1 Read the report Each finding is linked to the words it came from.

    22 mm observation with nonrim arterial phase hyperenhancement. Possible washout. No enhancing capsule.

  2. 2 Rules decide the category The published ACR table computes it. The model never does.
